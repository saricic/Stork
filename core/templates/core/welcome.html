FAQ

Short answers to common questions.

Is this the full Bolt experience?

No. It’s a Bolt-like booking flow with a warm, minimal design and a simple backend.

Can I add more pages later?

Yes — as long as we reuse the same driver.css components, everything stays consistent.

Where are Log in / Sign up links?

Always on the topbar (right side), so the page feels like a real product landing.

Can we change the text and sections?

Of course. This is a base landing page. We’ll iterate together.
